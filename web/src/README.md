# AngusAI - AI工作平台

基于 Dify AI 工作平台设计的现代化应用首页，提供全面的 AI 应用管理和团队协作功能。

## ✨ 主要功能

### 核心模块

- **工作台** - 数据概览、快速操作、最近使用
- **应用管理** - 创建、编辑、部署 AI 应用
- **工作流** - 可视化 AI 工作流设计与管理
- **知识库** - 文档和向量数据管理
- **数据集** - 训练和测试数据集管理
- **模型管理** - AI 模型配置与监控

### 团队协作

- **成员管理** - 团队成员邀请和权限管理
- **资源共享** - 应用、工作流等资源的团队共享
- **团队设置** - 团队信息和偏好配置

### 应用设置

- **API 密钥** - API 访问密钥管理
- **计费订阅** - 订阅计划和账单管理
- **使用分析** - API 使用统计和性能分析
- **插件市场** - 扩展功能插件

## 🌐 国际化支持

支持中文和英文两种语言，可在界面右上角切换。

### 语言配置文件

```
locales/
├── zh-CN.ts    # 中文翻译
└── en-US.ts    # 英文翻译
```

### 使用方式

```typescript
import { useLanguage } from './components/LanguageProvider';

function MyComponent() {
  const { t } = useLanguage();
  return <h1>{t('dashboard.welcome')}</h1>;
}
```

## 🎨 主题切换

支持浅色和深色两种主题模式：

- **浅色模式** - 适合白天使用
- **深色模式** - 适合夜间使用，减少眼睛疲劳

## 📱 响应式设计

完全响应式布局，支持：

- 桌面端（1920px+）
- 笔记本（1280px-1919px）
- 平板（768px-1279px）
- 移动端（<768px）

## 🛠️ 技术栈

- **React** - UI 框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式框架
- **Lucide React** - 图标库
- **ShadCN UI** - UI 组件库
- **Recharts** - 图表库
- **Sonner** - Toast 通知

## 📂 项目结构

```
├── components/              # 组件目录
│   ├── ui/                 # UI 基础组件
│   ├── figma/              # Figma 相关组件
│   ├── *Page*.tsx          # 页面组件
│   └── *Dialog*.tsx        # 对话框组件
├── locales/                # 国际化配置
│   ├── zh-CN.ts           # 中文翻译
│   └── en-US.ts           # 英文翻译
├── lib/                    # 工具库
│   └── i18n.ts            # 国际化配置
├── styles/                 # 样式文件
│   └── globals.css        # 全局样式
└── App.tsx                 # 应用入口

```
