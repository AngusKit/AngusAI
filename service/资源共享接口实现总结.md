## 核心功能特性

### 1. 权限管理
- 三级权限体系：VIEW（查看）、EDIT（编辑）、MANAGE（管理）
- 支持两种共享范围：ALL（全体成员）、SPECIFIC（指定成员）
- 成员级别权限可覆盖默认权限

### 2. 访问控制
- 所有者拥有完全控制权
- 全体成员共享：新成员自动获得访问权限
- 指定成员共享：只有明确授权的成员可访问
- 实时权限检查

### 3. 统计分析
- 访问次数统计（按操作类型）
- 独立访客数统计
- 访问趋势分析（支持按天、按周、按月）
- Top访问者排行
- 按小时访问分布

## 业务规则

1. **权限层级**: MANAGE > EDIT > VIEW
2. **所有者权限**: 所有者始终拥有MANAGE权限
3. **共享唯一性**: 同一资源只能有一个共享配置
4. **成员管理**: 只有所有者可以添加/移除成员
5. **访问控制**: 
   - ALL共享: 团队所有成员可访问
   - SPECIFIC共享: 只有指定成员可访问
6. **通知机制**: 支持在创建、更新、删除时通知成员

## 实现细节

### ResourceSharingCmdImpl - 命令服务实现

使用 `BizTemplate` 模式实现事务管理和参数校验:

#### 1. create() - 创建共享
- 检查资源是否已共享（避免重复）
- 检查共享范围和成员列表的有效性
- 创建共享记录，初始化统计数据
- 如果是指定成员共享，创建成员记录
- 使用 `insert0()` 保存实体，通过 `resourceSharingRepo.save()` 获取持久化对象

#### 2. update() - 更新共享
- 通过 `resourceSharingQuery.findById()` 查找实体
- 权限检查：只有所有者可更新
- 更新共享范围、权限
- 如果更新成员列表，先删除旧成员再添加新成员
- 使用 `resourceSharingRepo.save()` 保存更新

#### 3. delete() - 删除共享
- 通过 `resourceSharingQuery.findById()` 查找实体
- 权限检查：只有所有者可删除
- 先删除所有成员记录
- 使用 `resourceSharingRepo.deleteById()` 删除共享记录

#### 4. addMembers() - 批量添加成员
- 检查共享是否为指定成员类型
- 权限检查：只有所有者可添加成员
- 跳过已存在的成员
- 为每个新成员创建记录，使用共享的默认权限

#### 5. removeMember() - 移除成员
- 权限检查：只有所有者可移除成员
- 不能移除所有者自己
- 使用 `deleteBySharingIdAndUserId()` 删除成员记录

#### 6. recordAccess() - 记录访问
- 创建访问日志记录
- 根据操作类型更新统计数据（浏览量、编辑次数、下载次数）
- 更新成员的最后访问时间和访问次数
- 更新独立访客数

#### 7. cancelByResource() - 根据资源取消共享
- 通过资源ID和类型查找共享
- 权限检查：只有所有者可取消
- 删除所有成员和共享记录

**技术要点**:
- 所有方法使用 `@Transactional` 保证事务一致性
- `BizTemplate` 提供统一的参数校验和异常处理
- 通过 `ResourceSharingQuery` 查询实体，避免在 BizTemplate 内部调用父类方法
- 直接使用 repository 的 `save()` 和 `deleteById()` 方法，而非 `update0()` 和 `delete0()`
