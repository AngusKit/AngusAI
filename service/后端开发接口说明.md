# AngusAI 后端SpringBoot服务开发接口说明

## 项目结构概览

AngusAI后端服务采用分层架构设计，主要包含以下模块：

```
service/
├── api/          # API接口层 - 定义对外接口
├── core/         # 核心业务层 - 包含业务逻辑
├── boot/         # 启动模块 - 应用启动和配置
└── conf/         # 配置文件
```

## 核心模块详解

### 1. API模块 (`api/`)

- **作用**: 定义对外API接口和DTO
- **主要文件**:
    - `src/main/java/cloud/xcan/angus/` - 接口定义
    - `src/main/resources/i18n/` - 国际化资源文件

### 2. Core模块 (`core/`) - 核心业务层

采用DDD（领域驱动设计）分层架构：

```
core/src/main/java/cloud/xcan/angus/core/ai/
├── application/          # 应用层
│   ├── cmd/             # 命令处理
│   ├── converter/        # 数据转换器
│   └── query/            # 查询服务
├── domain/               # 领域层
│   ├── activity/         # 业务实体
│   ├── Constants.java    # 常量定义
│   └── MessageKeys.java  # 消息键
├── infra/                # 基础设施层
│   ├── installation/     # 安装配置
│   ├── job/              # 定时任务
│   ├── persistence/      # 数据持久化
│   ├── search/           # 搜索服务
│   └── util/             # 工具类
└── interfaces/           # 接口层
    └── activity/         # REST接口
        ├── ActivityRest.java           # REST控制器
        └── facade/                     # 门面模式
            ├── ActivityFacade.java     # 门面接口
            ├── dto/                    # 数据传输对象
            ├── vo/                     # 视图对象
            └── internal/               # 内部实现
```

### 3. Boot模块 (`boot/`) - 启动模块

- **主启动类**: `XCanAngusAIApplication.java`
- **配置文件**: `application.yml`
- **依赖管理**: 集成各种starter组件

## 核心类示例

### 1. REST控制器示例

```java
@Tag(name = "Activity", description = "User Activity Management")
@Validated
@RestController
@RequestMapping("/api/v1/activity")
public class ActivityRest {

  @Resource
  private ActivityFacade activityFacade;

  @Operation(summary = "Query activity logs")
  @GetMapping
  public ApiLocaleResult<PageResult<ActivityDetailVo>> list(
      @Valid @ParameterObject ActivityFindDto dto) {
    return ApiLocaleResult.success(activityFacade.list(dto));
  }
}
```

### 2. 领域实体示例

```java
@Entity
@Table(name = "activity")
@EntityListeners({TenantListener.class})
@Setter
@Getter
@Accessors(chain = true)
public class Activity extends TenantEntity<Activity, Long> {

  @Id

  @Column(name = "project_id")
  private Long projectId;
  
  @Column(name = "target_id")

  @Enumerated(EnumType.STRING)
  @Column(name = "type")
  private ActivityType type;
  
  @Column(name = "opt_date")
  private LocalDateTime optDate;
  
  private String description;
  private String detail;

```

### 4. 门面服务示例

```java
public interface ActivityFacade {
  PageResult<ActivityDetailVo> list(ActivityFindDto dto);
}

@Component
public class ActivityFacadeImpl implements ActivityFacade {

  @Resource
  private ActivityQuery activityQuery;

  @Override
  public PageResult<ActivityDetailVo> list(ActivityFindDto dto) {
    Page<Activity> page = activityQuery.find(getSpecification(dto), dto.tranPage(),
        dto.fullTextSearch, getMatchSearchFields(dto.getClass()));
    return buildVoPageResult(page, ActivityAssembler::toDetailVo);
  }
}
```

### 5. 查询服务示例

```java
@Biz
@SummaryQueryRegister(name = "Activity", table = "activity", groupByColumns = {"opt_date", "target_type"})
public class ActivityQueryImpl implements ActivityQuery {

  @Resource
  private ActivityRepo activityRepo;

  @Override
  public Page<Activity> find(GenericSpecification<Activity> spec, PageRequest pageable,
      boolean fullTextSearch, String[] match) {
    return new BizTemplate<Page<Activity>>() {
      @Override
      protected Page<Activity> process() {
        Page<Activity> page = fullTextSearch
            ? activitySearchRepo.find(spec.getCriteria(), pageable, Activity.class, match)
            : activityListRepo.find(spec.getCriteria(), pageable, Activity.class, null);
        
        if (page.hasContent()) {
          userManager.setUserNameAndAvatar(page.getContent(), "userId", "fullName", "avatar");
        }
        return page;
      }
    }.execute();
  }
}
```

## 快速开发接口指南

### 1. 创建新接口的步骤

1. **创建领域实体** (`domain/`)
    - 继承 `TenantEntity<Entity, Long>`
    - 使用JPA注解定义表结构
    - 添加 `@EntityListeners({TenantListener.class})`

2. **创建仓储接口** (`domain/`)
    - 继承 `BaseRepository<Entity, Long>`
    - 定义查询方法
    - 使用 `@Query` 注解编写自定义SQL

3. **创建DTO和VO** (`interfaces/facade/`)
    - DTO: 请求参数对象，继承 `PageQuery`
    - VO: 响应对象，使用 `@Schema` 注解

4. **创建门面接口** (`interfaces/facade/`)
    - 定义业务接口方法
    - 实现类注入查询服务

5. **创建REST控制器** (`interfaces/`)
    - 使用 `@RestController` 和 `@RequestMapping`
    - 添加Swagger注解 `@Tag`, `@Operation`
    - 注入门面服务

### 2. 常用注解说明

- `@Entity`: JPA实体类
- `@Table`: 指定数据库表名
- `@Column`: 字段映射
- `@Enumerated`: 枚举类型映射
- `@Transient`: 非持久化字段
- `@Tag`: Swagger API分组
- `@Operation`: API操作描述
- `@Schema`: 字段描述
- `@Valid`: 参数验证
- `@Resource`: 依赖注入

### 3. 配置说明

- **数据库**: 支持MySQL和PostgreSQL
- **缓存**: 集成Redis和Caffeine二级缓存
- **搜索**: 支持全文搜索
- **国际化**: 多语言支持
- **日志**: 集成Logback
- **API文档**: 自动生成Swagger文档

### 4. 开发最佳实践

1. **分层清晰**: 严格按照DDD分层架构
2. **命名规范**: 使用有意义的类名和方法名
3. **异常处理**: 使用统一的异常处理机制
4. **数据验证**: 使用Bean Validation进行参数验证
5. **事务管理**: 合理使用 `@Transactional` 注解
6. **缓存策略**: 合理使用缓存提升性能
7. **API文档**: 完善Swagger注解

### 5. 启动配置

- **端口**: 默认1530
- **上下文路径**: `/`
- **配置文件**: `application.yml`
- **日志配置**: `spring-logback.xml`
- **健康检查**: `/actuator/health`

这个架构设计支持快速开发RESTful API，具有良好的可维护性和扩展性。
