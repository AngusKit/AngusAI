## 已实现的功能模块

### 1. 用户设置模块

#### 实体设计
- **UserSettings**: 用户基本设置实体
  - 基本信息:姓名、邮箱、头像、电话、公司、职位
  - 时区和语言设置
  - 偏好设置(JSON格式存储)
  - 隐私设置(JSON格式存储)
  - 通知设置(JSON格式存储)
  - 账户删除相关字段

#### 接口实现
- `GET /api/v1/settings/profile` - 获取用户设置
- `PATCH /api/v1/settings/profile` - 更新用户设置
- `POST /api/v1/settings/avatar` - 上传头像
- `DELETE /api/v1/settings/avatar` - 删除头像

### 2. 通知设置模块

#### 数据结构
- **EmailNotification**: 邮件通知(启用/禁用、频率、具体类型)
- **BrowserNotification**: 浏览器通知
- **InAppNotification**: 应用内通知
- **MobileNotification**: 移动推送(含免打扰时间)

#### 接口实现
- `GET /api/v1/settings/notifications` - 获取通知设置
- `PATCH /api/v1/settings/notifications` - 更新通知设置

### 3. 安全设置模块

#### 实体设计
- **SecuritySettings**: 安全设置实体
  - 双因素认证设置(方法、密钥、备用码)
  - 会话管理设置(最大会话数、超时时间)
  - 密码策略(最后修改时间、过期天数)
  - IP白名单设置

- **UserSession**: 用户会话实体
  - 会话信息(设备、浏览器、IP、位置)
  - 活跃时间、过期时间

- **LoginHistory**: 登录历史实体
  - 登录时间、IP、位置、设备、浏览器
  - 登录状态(成功/失败)、失败原因

#### 接口实现
- `GET /api/v1/settings/security` - 获取安全设置
- `POST /api/v1/settings/security/2fa/enable` - 启用双因素认证
- `POST /api/v1/settings/security/2fa/verify` - 验证双因素认证
- `POST /api/v1/settings/security/2fa/disable` - 禁用双因素认证
- `POST /api/v1/settings/security/change-password` - 修改密码
- `DELETE /api/v1/settings/security/sessions/:sessionId` - 终止指定会话
- `POST /api/v1/settings/security/sessions/revoke-all` - 终止所有其他会话

### 4. 数据导出模块

#### 实体设计
- **DataExport**: 数据导出实体
  - 导出类型(完整/部分)
  - 导出格式(JSON/CSV/ZIP)
  - 导出状态(处理中/完成/失败)
  - 导出范围、文件大小、下载链接
  - 请求时间、完成时间、过期时间

#### 接口实现
- `GET /api/v1/settings/data-export` - 获取数据导出记录
- `POST /api/v1/settings/data-export` - 请求数据导出

### 5. 账户管理模块

#### 功能特性
- 账户删除请求(30天宽限期)
- 取消删除请求
- 删除原因和反馈收集

#### 接口实现
- `POST /api/v1/settings/delete-account` - 请求删除账户
- `POST /api/v1/settings/cancel-delete-account` - 取消删除账户

## 架构特点

### 1. 分层架构
严格遵循DDD分层架构:
- **领域层(Domain)**: 实体、值对象、仓储接口
- **应用层(Application)**: 查询服务(Query)、命令服务(Cmd)
- **接口层(Interfaces)**: REST控制器、门面模式、DTO/VO

### 2. 业务逻辑封装
- 使用`BizTemplate`模式统一处理业务逻辑
- 分离参数校验(`checkParams`)和业务处理(`process`)
- 统一异常处理和事务管理

### 3. 数据转换
- **DTO**: 接收客户端请求参数
- **Entity**: 领域实体,与数据库映射
- **VO**: 返回给客户端的视图对象

### 4. 持久化设计
- JPA实体映射,支持多租户
- 使用`TenantAuditingEntity`基类,自动处理审计字段
- JSON类型字段存储复杂对象(偏好设置、通知设置等)

## 关键技术点

### 1. JSON字段存储
使用`@Type(JsonType.class)`注解将复杂对象以JSON格式存储:
```java
@Type(JsonType.class)
@Column(columnDefinition = "json", name = "preferences")
private UserPreferences preferences;
```

### 2. 枚举类型
使用`@Enumerated(EnumType.STRING)`存储枚举:
```java
@Enumerated(EnumType.STRING)
@Column(name = "two_factor_method", length = 20)
private TwoFactorMethod twoFactorMethod;
```

### 3. 仓储查询
继承`BaseRepository`,支持自定义查询:
```java
@Query("SELECT COUNT(s) FROM UserSession s WHERE s.userId = ?1 AND s.expiresAt > ?2")
int countActiveSessionsByUserId(Long userId, LocalDateTime now);
```

### 4. Swagger文档
完整的API文档注解:
- `@Tag`: API分组
- `@Operation`: 操作描述
- `@Parameter`: 参数说明
- `@Schema`: 字段描述

### 4. 通知频率

- **daily**: 每日汇总
- **weekly**: 每周汇总

## 开发规范

### 1. 命名规范
- 实体类:名词,如`UserSettings`
- DTO:动作+Dto,如`UserSettingsUpdateDto`
- VO:名词+Vo,如`UserSettingsVo`
- 接口:名词,如`SettingsFacade`
- 实现类:接口名+Impl,如`SettingsFacadeImpl`

### 2. 注解使用
- 实体类:`@Entity`, `@Table`, `@Column`
- REST控制器:`@RestController`, `@RequestMapping`
- 验证:`@Valid`, `@NotNull`, `@Size`
- 文档:`@Tag`, `@Operation`, `@Schema`

### 3. 异常处理
- 使用统一异常:`ResourceNotFound`, `IllegalArgumentException`
- 通过`BizTemplate`统一捕获和处理

**设计特点**:
- 静态工具类,无状态设计
- 完整的中文标签映射

### 3. ResourceSharingFacadeImpl (门面实现)
**文件位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/interfaces/settings/facade/internal/ResourceSharingFacadeImpl.java`

**实现的11个方法**:

#### 3.1 CRUD操作
1. **create()** - 创建共享
   - 调用Cmd.create()创建记录
   - 查询成员列表
   - 转换为DetailVo返回

2. **list()** - 分页列表
   - 调用Query.list()获取分页数据
   - 逐个查询成员数量
   - 转换为ListVo + PageResult

3. **getDetail()** - 获取详情
   - 调用Query.getDetail()
   - 查询成员列表
   - 转换为DetailVo(含成员信息)

4. **update()** - 更新共享
   - 调用Cmd.update()
   - 查询最新成员列表
   - 返回更新后的DetailVo

5. **delete()** - 删除共享
   - 调用Cmd.delete()
   - TODO: 通知被共享成员

#### 3.2 成员管理
6. **addMembers()** - 批量添加成员
   - 调用Cmd.addMembers()
   - 返回Map包含: success, addedCount, members

7. **removeMember()** - 移除成员
   - 调用Cmd.removeMember()
   - TODO: 通知被移除的成员

#### 3.3 权限与访问
8. **checkAccess()** - 检查访问权限
   - 调用Query.hasAccess()判断是否有权限
   - 调用Query.getUserPermission()获取权限级别
   - 构造ResourceAccessCheckVo返回

9. **recordAccess()** - 记录访问日志
   - 调用Cmd.recordAccess()记录
   - 用于统计和审计

#### 3.4 统计功能
10. **getStatistics()** - 获取共享统计
    - 调用Query.getDetail()
    - 构造统计Map(总浏览、总成员、创建时间等)

11. **getMyStatistics()** - 获取用户统计
    - 调用Query.getUserStatistics()
    - 构造嵌套VO结构:
      * SharedByMeVo: 我创建的共享(总数、浏览量、成员数、按类型统计)
      * SharedToMeVo: 共享给我的(总数、最近访问、按类型统计)
