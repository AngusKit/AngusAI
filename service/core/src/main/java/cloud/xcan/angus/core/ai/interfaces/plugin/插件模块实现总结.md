# 插件模块实现总结

## 概述
参考应用接口实现，已完成插件(Plugin)模块的完整接口和业务层实现，遵循DDD架构设计。

## 已创建的文件结构

### 1. Domain层 (领域层)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/domain/plugin/`

- `Plugin.java` - 插件实体类
- `PluginCategory.java` - 插件分类枚举
- `PluginStatus.java` - 插件状态枚举
- `PluginType.java` - 插件类型枚举
- `PluginConfig.java` - 插件配置类
- `PluginPermissions.java` - 插件权限配置
- `PluginTag.java` - 插件标签
- `PluginRepo.java` - 插件仓储接口

#### 核心实体字段
```java
- id, name, nameEn, icon, description
- author, version, category, status, type
- config(JSON), permissions(JSON), tags(JSON)
- installCount, usageCount, rating, reviewCount
- isFavorite, isSystem, isPublic, isVerified
- minVersion, urls(homepage, docs, repo, support)
- license, price, currency
- publishedDate, tenantId, createdBy/Date, lastModifiedBy/Date
```

### 2. Application层 (应用层)

#### Command (命令)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/application/cmd/plugin/`

- `PluginCmd.java` - 插件命令接口
- `impl/PluginCmdImpl.java` - 插件命令实现

**核心方法**:
- `create()` - 创建插件
- `duplicate()` - 复制插件
- `update()` - 更新插件
- `updateConfig()` - 更新配置
- `modifyStatus()` - 修改状态
- `delete()` - 删除插件
- `favorite()` - 收藏/取消收藏
- `install()/uninstall()` - 安装/卸载
- `use()` - 使用（增加计数）
- `publish()` - 发布插件
- `verify()` - 验证插件

#### Query (查询)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/application/query/plugin/`

- `PluginQuery.java` - 插件查询接口
- `impl/PluginQueryImpl.java` - 插件查询实现

**核心方法**:
- `find()` - 条件查询
- `findById()/findByName()` - 单个查询
- `findByCategory/Status/Type()` - 按属性查询
- `findPublic/System/VerifiedPlugins()` - 特定类型查询
- `findTrendingPlugins()` - 热门插件
- `search()` - 搜索
- `count*()` - 统计方法

### 3. Interfaces层 (接口层)

#### DTO (数据传输对象)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/interfaces/plugin/facade/dto/`

- `PluginCreateDto.java` - 创建插件请求
- `PluginUpdateDto.java` - 更新插件请求
- `PluginFindDto.java` - 查询插件请求
- `PluginDuplicateDto.java` - 复制插件请求
- `PluginFavoriteDto.java` - 收藏请求
- `PluginInstallDto.java` - 安装请求

#### VO (视图对象)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/interfaces/plugin/facade/vo/`

- `PluginDetailVo.java` - 插件详情
- `PluginListVo.java` - 插件列表项
- `PluginStatisticsVo.java` - 插件统计数据

#### Facade (门面)
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/interfaces/plugin/facade/`

- `PluginFacade.java` - 插件门面接口
- `internal/PluginFacadeImpl.java` - 插件门面实现
- `internal/assembler/PluginAssembler.java` - 数据转换器

**核心能力**:
- CRUD操作
- 收藏管理
- 安装/卸载
- 发布/验证
- 统计查询
- 搜索/热门

#### REST Controller
**位置**: `service/core/src/main/java/cloud/xcan/angus/core/ai/interfaces/plugin/`

- `PluginRest.java` - 插件REST控制器

**API端点**:
```
POST   /api/v1/plugins              - 创建插件
POST   /api/v1/plugins/{id}/duplicate - 复制插件
PATCH  /api/v1/plugins/{id}         - 更新插件
PUT    /api/v1/plugins/{id}/config  - 更新配置
PUT    /api/v1/plugins/{id}/status  - 修改状态
DELETE /api/v1/plugins/{id}         - 删除插件
GET    /api/v1/plugins/{id}         - 获取详情
GET    /api/v1/plugins              - 获取列表
POST   /api/v1/plugins/{id}/favorite - 收藏/取消
POST   /api/v1/plugins/{id}/install - 安装
POST   /api/v1/plugins/{id}/uninstall - 卸载
POST   /api/v1/plugins/{id}/use     - 使用
POST   /api/v1/plugins/{id}/publish - 发布
PUT    /api/v1/plugins/{id}/verify  - 验证
GET    /api/v1/plugins/statistics   - 获取统计
GET    /api/v1/plugins/search       - 搜索
GET    /api/v1/plugins/trending     - 热门插件
```

## 技术特点

### 1. DDD架构
- Domain: 领域模型和业务规则
- Application: 应用服务和查询
- Interfaces: 对外接口和数据转换

### 2. 设计模式
- Repository模式: 数据持久化
- Facade模式: 接口门面
- Assembler模式: DTO/Domain/VO转换
- CQRS: 命令查询分离

### 3. 数据存储
- JPA实体映射
- JSON类型存储复杂配置
- 多租户支持
- 审计字段(@NameJoin)

### 4. API设计
- RESTful风格
- OpenAPI/Swagger文档
- 统一响应格式(ApiLocaleResult)
- 分页支持(PageResult)
- 参数验证(@Valid)

## 数据库表设计

需要创建以下表:
```sql
CREATE TABLE plugin (
  id BIGINT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  name_en VARCHAR(100),
  icon VARCHAR(255),
  description VARCHAR(500),
  author VARCHAR(100),
  version VARCHAR(20) NOT NULL,
  category VARCHAR(50) NOT NULL,
  status VARCHAR(20) NOT NULL,
  type VARCHAR(20) NOT NULL,
  config JSON,
  permissions JSON,
  tags JSON,
  install_count BIGINT DEFAULT 0,
  usage_count BIGINT DEFAULT 0,
  rating DOUBLE DEFAULT 0.0,
  review_count BIGINT DEFAULT 0,
  is_favorite BOOLEAN DEFAULT FALSE,
  is_system BOOLEAN DEFAULT FALSE,
  is_public BOOLEAN DEFAULT FALSE,
  is_verified BOOLEAN DEFAULT FALSE,
  min_version VARCHAR(20),
  homepage_url VARCHAR(500),
  documentation_url VARCHAR(500),
  repository_url VARCHAR(500),
  support_url VARCHAR(500),
  license VARCHAR(50),
  price DOUBLE DEFAULT 0.0,
  currency VARCHAR(10) DEFAULT 'CNY',
  published_date DATETIME,
  tenant_id BIGINT,
  created_by BIGINT,
  created_date DATETIME,
  last_modified_by BIGINT,
  last_modified_date DATETIME,
  INDEX idx_category (category),
  INDEX idx_status (status),
  INDEX idx_type (type),
  INDEX idx_tenant (tenant_id),
  INDEX idx_creator (created_by)
);
```

## 编译注意事项

目前存在一些编译错误,这是正常的:
1. `BusinessException` vs `ResourceNotFound` - 异常类型选择
2. `SearchCriteriaBuilder` - 泛型边界问题
3. 部分import缺失

这些问题可以通过以下方式修复:
- 统一使用项目中已有的异常类
- 参考ApplicationAssembler修正SearchCriteriaBuilder使用
- 补充必要的import语句
