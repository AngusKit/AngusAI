## 1. 内容创作类

### 文章写作

```
请以[主题]为主题，撰写一篇[文章类型]文章。

写作要求：
1. 目标读者：[读者群体特征和知识水平]
2. 文章长度：[字数范围，如800-1200字]
3. 核心观点：[主要论点和价值主张]
4. 文章结构：[引言-正文-结论/其他结构]
5. 写作风格：[正式/轻松/专业/活泼等]
6. 关键词：[重要关键词列表，用于SEO]

内容要求：
- 原创性：确保内容原创，避免抄袭
- 逻辑性：结构清晰，论证严密
- 可读性：语言流畅，表达准确
- 价值性：提供实用信息或独特见解

请确保文章符合以上要求，并提供文章大纲和正文。
```

## 使用说明

### 提示词使用原则

1. **明确目标**：在使用提示词前，明确你的具体目标和需求
2. **替换占位符**：将提示词中的`[占位符]`替换为具体内容
3. **调整细节**：根据实际情况调整提示词的细节要求
4. **迭代优化**：根据输出结果，不断优化和调整提示词

### 提示词优化技巧

1. **具体化**：使用具体、明确的描述，避免模糊表达
2. **结构化**：使用清晰的层次结构，便于理解和执行
3. **约束化**：明确输出格式、长度、风格等约束条件
4. **示例化**：提供示例可以帮助模型更好地理解需求

本提示词库按照功能和应用场景进行分类，每个分类下包含多个子分类。你可以根据具体需求选择合适的提示词模板，并根据实际情况进行调整和优化。
